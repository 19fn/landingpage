19fn / landingpagemain
  1. Stage 01 · ProvisionInfrastructure as code

    Terraform provisions an Azure Storage static website behind Azure Front Door, with a custom domain and managed HTTPS, and publishes only the public files.

    • Terraform
    • Azure Front Door
  2. Stage 02 · ScanSecurity scanning

    CodeQL analyzes the code and Gitleaks scans the full Git history for secrets on every push and every week.

    • CodeQL
    • Gitleaks
  3. Stage 03 · ValidateAutomated checks

    Every pull request and push validates the site files and the Terraform formatting and configuration.

    • GitHub Actions
    • terraform validate
  4. Stage 04 · DeployPasswordless deploys

    GitHub Actions signs in to Azure with OIDC federation, so no cloud secrets are stored, uploads with a least-privilege role, and then checks the live site's health endpoint.

    • OIDC
    • Least privilege
