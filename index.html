Curiosity became
a practice.

Technology caught my attention early. By twelve I had taught myself to code, and running Minecraft servers became my first real lesson in infrastructure, automation, troubleshooting, and system design.

That curiosity grew into a career that started in DevOps and moved into cloud architecture, security, and AI. Today I like to own problems end to end: I work with product and engineering teams to turn ideas into production-ready software, from the first architecture decision through implementation, troubleshooting, and delivery.

The mindset: continuous improvement, useful failures, and constant adaptation.

  1. Stage 01 · ProvisionInfrastructure as code

    • CloudFront

  2. Stage 02 · ScanSecurity scanning

    CodeQL analyzes the code and Gitleaks scans the full Git history for secrets on every push and every week.

    • CodeQL
    • Gitleaks
  3. Stage 03 · ValidateAutomated checks

    Every pull request and push validates the site files and the Terraform formatting and configuration. Deploys run the same checks first, so nothing ships if one fails.

    • GitHub Actions
    • terraform validate
  4. Stage 04 · DeployPasswordless deploys

    GitHub Actions signs in to AWS with OIDC federation, so no cloud secrets are stored, syncs the files to S3 with a least-privilege role, invalidates the CloudFront cache, and then checks the live site's health endpoint.

    • Least privilege
